End-to-End System Pipeline

Kiosk Frontend → Edge API Gateway → Redis → Microservices → Persistence & Cloud

Active Pipeline
1. Client Kiosk UI & WebRTC Stream Frontend Runtime

Touchscreen SPA runtime (HTML5/Next.js). Encodes 320x240 @ 10fps surveillance stream. Manages local UI state machine and cross-tab BroadcastChannel event bus.

2. Edge API Gateway & Reverse Proxy Express / Port 3000

Reverse proxy with token-bucket rate limiting (100 req/min), CORS security, path-traversal sanitization, TLS termination, and microservice route dispatching.

3. Redis In-Memory Cache & Pub/Sub Sub-millisecond

Hot key-value caching for active sessions (sess:TTL), single-use QR token verification, distributed Redlock concurrency locks, and real-time Pub/Sub event broadcasting.

4. Core Business Microservices Reward & Orders

Independent microservices execute dynamic discount formula min(25%, 5% + (w-50)/50), mint tamper-proof vouchers, and manage order dispensing lifecycle state machines.

5. Database & ACID Persistence MongoDB / Postgres

ACID transactional store for orders, disposals, and inventory slots. Atomic local file mutex persistence in data/sdds-state.json provides 100% offline edge resilience.

6. Payment Gateway Integration Razorpay / Stripe

Generates dynamic UPI QR codes with paise currency conversion. Asynchronous webhook handlers verify HMAC SHA-256 cryptographic signatures before authorizing order fulfillment.

7. Cloud Storage & Video Ingestion AWS S3 / Cloud Blob

Multipart ingestion pipeline uploads 60-second video chunk slices (POST /api/v1/recordings/chunk) to cloud object storage with 30-day lifecycle expiration.

8. Central Admin & Observability Prometheus / Ledger

Prometheus telemetry endpoints (/metrics) and unified audit ledger stream real-time events across multi-kiosk deployments to admin.html.
